# Terraform provider for Mockingbird

Manages [Mockingbird](https://github.com/RJ-s-Org/Mockingbird) mocks, contracts, scenarios, LLM profiles, API keys and event settings through the Admin API, from Terraform or OpenTofu (and Pulumi, through its Terraform bridge).

```hcl
terraform {
  required_providers {
    mockingbird = { source = "RJ-s-Org/mockingbird" }
  }
}

provider "mockingbird" {} # MB_ADMIN_URL, MB_ADMIN_TOKEN, MB_DATA_PLANE_URL

resource "mockingbird_mock" "stripe" {
  name         = "stripe"
  route_prefix = "/stripe"
  persona      = "Stripe in test mode for Juniper & Co, a plant shop in Portland."
  contract     = { file = "contracts/stripe.openapi.yaml" }
}

output "stripe_api_base" { value = mockingbird_mock.stripe.url }
```

- Reference: [`docs/`](docs/index.md) (generated by `make docs`), with examples in [`examples/`](examples).
- Guide, walkthrough, Pulumi and publishing steps: [docs/iac.md](https://github.com/RJ-s-Org/Mockingbird/blob/main/docs/iac.md) in the Mockingbird repository.

## Development

Go 1.25 or later. The acceptance tests start `mockingbird serve --offline` on free ports and run every resource through real Terraform or OpenTofu:

```sh
make build          # go build + go vet
make test           # unit tests
make testacc        # acceptance tests with Terraform (MOCKINGBIRD_BIN=path/to/mockingbird)
make testacc-tofu   # the same with OpenTofu
make docs           # regenerate docs/ from the schema, templates and examples
```

Inside the Mockingbird repository the tests use `../../target/debug/mockingbird` (`cargo build -p mockingbird`); set `MOCKINGBIRD_BIN` elsewhere, or `MB_ADMIN_URL` to test against a running server.

Releases are built by `.github/workflows/release.yml` with goreleaser on a `v*` tag and signed with the GPG key in the `GPG_PRIVATE_KEY` secret.
